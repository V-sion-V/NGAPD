## 结论摘要

使用与 macOS 主体相同的夹具和无头 runner 执行，12 个 core 场景全部通过。正常预算下必需来源需要 `3050` tokens，最终选用 `5810`，剩余 `190`；低于 `3050` 时稳定拒绝，不产生部分 manifest 或任务分析。

manifest 共包含 28 个可诊断条目。所有分页组合逐项等于未分页结果；预算变化后旧游标稳定失效。逐次重新授权、来源版本失效、跨用户边界、提示注入与三类摘要来源均保持 P-001 定义的行为。

工具授权在加入提示注入材料前后逐字段保持：

```json
{
  "readScope": "selected_sources",
  "writeScope": "none",
  "adminMode": false,
  "lease": false,
  "requiresConfirmation": true
}
```

本次执行只读取内存合成值和仓库内合成夹具；没有登录、数据库、Web、真实 Workspace、生产授权修改、外部发送、API、AI/LLM、Skill 执行、管理员模式或写租约。

## 性能

测量只覆盖最终 manifest 生成，不包含渐进正文读取。每种规模预热后重复 80 次，门禁为 P95 `< 1000 ms`。

| 规模 | 任务 | 依赖 | Agent Context 来源 | P95 | 最大值 | 结论 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| deep-tree | 24 | 5 | 29 | `0.575 ms` | `1.498 ms` | pass |
| wide-siblings | 205 | 300 | 29 | `1.319 ms` | `1.619 ms` | pass |
| dense-dag | 36 | 48 | 29 | `0.580 ms` | `0.774 ms` | pass |

三种规模、专项分页场景和 page size `4` 继续覆盖 `AC-022` 的低成本附加规模检查；规范化 `sortKey`、reason、游标绑定和场景输出继续提供 `AC-023` 诊断面。未观察到 supplemental 异常。
